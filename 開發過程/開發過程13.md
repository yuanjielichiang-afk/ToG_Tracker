- **致命 Bug 原理解析**：
  原始 HTML 中的檔案解析函式 `parseFile` 寫死為讀取「純兩欄格式（`x, y`）」。
  但我們匯出的 `Track_A_GroundTruth.txt` 包含表頭與幀號：
  ```csv

  0,0.000,0.000,T
  1,0.052,0.000,T
  100,5.150,-0.010,TL
  ```
  舊版解析器粗暴地把第 0 欄（`frame`）當成 X、第 1 欄（`x`）當成 Y，而真正的第 2 欄（`y`）完全被拋棄！
  因此 UI 畫出來的不是 2D 平面圓，而是「X 坐標隨幀號變化的展開波形」，軌跡自然完全走樣！

  已在 [export_tracks_and_build_html.py](file:///C:/PROJECT/ToG_Tracker/export_tracks_and_build_html.py) 重寫智能欄位解析器：
  - 自動識別 `#frame, x, y, err, intervened, zone, squal` 等表頭欄位名稱。
  - 精準鎖定真實的 X 與 Y 坐標，並同步讀入紅叉介入點與綠色微塵帶。
  - 現在從 UI 上傳任何歷史導出的 `Track_*.txt`，皆能百分之百正確繪製出標準的 2D 閉環圓軌跡！
