### 二、 `self.global_x` 是否直接取自 Ground Truth 累積位置？

**明確解答：不是！`self.global_x` 絕非直接從 Ground Truth 取出來的。**

以下為該段程式碼在狀態機中的詳細拆解：

```python
        # 1. 預測搜尋中心 (完全由追蹤器自身歷史狀態估算，不依賴真值)
        px, py, pred_dx_rel, pred_dy_rel = self.predict_displacement()
        pred_gx = (self.global_x - self.last_dx_rel) + pred_dx_rel
        pred_gy = (self.global_y - self.last_dy_rel) + pred_dy_rel
```

1. **`self.global_x` 的生命週期**：
   - **第 0 幀**：僅在起始時刻初始化為原點 `self.global_x = gth_pos[0]`（即 $0.0$）。
   - **後續每一幀**：`self.global_x` 是演算法自己將每幀測得的 `frame_dx` **內部累加**得到的估計位置：
     $$\text{self.global\_x} \leftarrow \text{self.global\_x} + frame\_dx$$
2. **`pred_gx` 的物理意義**：
   - `self.last_dx_rel` 是當前幀相對於「參考關鍵幀 (Keyframe)」的相對累積量。
   - `(self.global_x - self.last_dx_rel)` 代表**演算法內部估計的當前 Keyframe 全域座標**。
   - `pred_dx_rel` 是利用內部 IIR 速度濾波器預測出的相對位移。
   - 兩者相加得到的 `pred_gx`，是**演算法自主預估自己當前應該落在哪個全域座標**。
3. **Teacher 介入的真正條件**：
   算完完全自主的 `pred_gx` 之後，才會拿去與傳入的真值 `gth_pos[0]` 比對：
   ```python
   pos_err_x = abs(round(pred_gx) - gth_pos[0])
   pos_err_y = abs(round(pred_gy) - gth_pos[1])
   in_basin = (pos_err_x <= 1.0 and pos_err_y <= 1.0)
   ```
   - **當 `in_basin` 為 True（未脫靶）**：Teacher 靜默，搜尋中心 `px, py` 維持自主預測。
   - **當 `in_basin` 為 False（脫靶失步）**：Teacher 才強行介入，將比對中心重設回真值位置。

### 三、 滑鼠墊紋理鋸齒狀成因與 `OptNavi.cpp` Corner 濾波器解析

您在實測中觀察到的「鋸齒狀（Sawtooth Jitter）」現象完全正確！

#### 1. 鋸齒狀的物理成因：
- 布質滑鼠墊由經緯紗線編織而成，在 $0^\circ$ 與 $90^\circ$ 方向具有強烈的**週期性條紋（Repeat Pattern）**。
- 若直接對灰階影像做相關匹配（ZNCC），相關曲面（Correlation Surface）會沿著紗線方向形成狹長的「相關脊線（Ridge）」或「週期性假谷值/假峰值」。
- 在次像素拋物線插值時，匹配中心會在相鄰織紋週期之間來回跳動（在 `MousePad-1` 中 $dx$ 來回跳動了 3,600+ 次），反映在全域軌跡上就是顯著的高頻鋸齒。

#### 2. `OptNavi.cpp` 中的 `xSurfaceAlignFilterCorner` 機制：
參閱 [OptNavi.cpp](file:///C:/PROJECT/Navi/modules/navi/src/OptNavi.cpp) 的核心實作，其打破 Repeat Pattern 的精妙演算法如下：

1. **4 個角度二階差分濾波核**：
   - $0^\circ$（垂直二階）：$\begin{bmatrix} 0 & -1 & 0 \\ 0 & 2 & 0 \\ 0 & -1 & 0 \end{bmatrix}$
   - $45^\circ$（對角二階）：$\begin{bmatrix} -1 & 0 & 0 \\ 0 & 2 & 0 \\ 0 & 0 & -1 \end{bmatrix}$
   - $90^\circ$（水平二階）：$\begin{bmatrix} 0 & 0 & 0 \\ -1 & 2 & -1 \\ 0 & 0 & 0 \end{bmatrix}$
   - $135^\circ$（反對角二階）：$\begin{bmatrix} 0 & 0 & -1 \\ 0 & 2 & 0 \\ -1 & 0 & 0 \end{bmatrix}$
2. **方向各向異性判斷**：
   取出 4 個方向響應的絕對值最大值 `maxAlignVal`、最小值 `minAlignVal`，以及非方向基準 `noAlignVal = (val045 + val135) / 2`。
3. **打破 Repeat Pattern 的替換邏輯**：
   ```cpp
   if (abs(maxAlignVal) - abs(minAlignVal) > abs(noAlignVal) + flatFilterBias) {
       pSurfAlign[c] = abs(minAlignVal); // 強方向性條紋處：壓制主方向，改取各向同性分量
   } else {
       pSurfAlign[c] = noAlignVal;        // 一般平緩區域
   }
   ```
   當檢測到某方向響應遠大於另一方向時，判定該像素落於單向週期織紋上，**主動剔除主方向條紋響應，強制改取各向同性響應 `abs(minAlignVal)`**，藉此摧毀單向週期脊線，凸顯真實的 2D 角點（Corner/Junction）特徵！
